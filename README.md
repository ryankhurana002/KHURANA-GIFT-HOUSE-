# Khurana Gift House — rebuilt website

This is a fresh, responsive static website using the actual product photos supplied in the chat. It does not use AI-generated replacement product photos.

## Run on your computer
1. Extract this ZIP.
2. Open the extracted `khurana-gift-house-new` folder in VS Code.
3. Open Terminal in VS Code (Terminal → New Terminal).
4. Run: `py -m http.server 5500`
5. Open `http://localhost:5500` in your browser.
6. To stop the server, click the terminal and press `Ctrl + C`.

If the `py` command does not work, try `python -m http.server 5500`.
